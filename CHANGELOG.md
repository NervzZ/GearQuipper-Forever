# Changelog

## 1.0.0

First public release of GearQuipper Forever on CurseForge, for WoW Forever.

- GearQuipper revived for WoW Forever's client: full and partial gear sets, with identical rings, trinkets and weapons handled correctly
- A panel docked to the character sheet with Sets and Events tabs, set rows with icon, tick and spec badge, and a right-click menu
- Hover quick bars on the equipment slots, in the look of Blizzard's equipment flyout with rarity borders
- A set per spec, and automatic swaps on events such as mounting, battlegrounds, zones, combat, forms and stances
- Fast switching that waits for the server instead of fixed timers; armor changes in combat wait for the end of combat
- Push a set into the bank or take it back in one click
- Set colours in the set list, in item tooltips and on the character sheet
- Sell protection: at a vendor, set items in your bags are greyed out with a red cross and a right-click asks before selling; items sold another way are bought back and you are asked
- Delete protection: the delete prompt stays locked until you confirm in GearQuipper's warning
- Follows EllesmereUI's look while its character-sheet skin is on; ElvUI support included but untested
